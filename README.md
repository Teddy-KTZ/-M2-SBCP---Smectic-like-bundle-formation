# Numeric Physics project - Smectic-like bundle formation
## For your information
This repository is made to keep a trace of the work done on the numerical physics project for M2 SBCP of Sorbonne University. 

This project is based on the smectic-like bundle formation of planktonic bacteria upon nutrient starvation paper from Kazumasa Takeuchi Grop (Tokyo University, Hongo campus). 

Code and document will be writen in French.
